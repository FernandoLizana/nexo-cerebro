# P7 — Reporting

`aggregate_and_report()` writes:

| Artifact | Format |
|----------|--------|
| `population_report.json` | Full structured report |
| `population_report.md` | Human-readable summary |
| `runs.csv` | Per-run status + NCFS/CRS |
| `aggregates/cohorts.json` | Cohort breakdown |
| `aggregates/failures.json` | Failure clusters |

Both EN and ES simulation disclaimers included. Reports never claim human population calibration.
