# P7 — Cohort Comparison

When ≥2 cohorts exist, aggregator emits pairwise comparisons vs `baseline` (or first cohort):

- `ncfs_median_delta` — difference in median NCFS
- `valid_runs_a` / `valid_runs_b` — denominators explicit

Effect sizes and bootstrap CIs deferred to future phases; no false precision at small N.
